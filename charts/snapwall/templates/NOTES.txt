SnapWall {{ include "snapwall.version" . }} is deploying to namespace {{ .Release.Namespace }}.
The cluster name and URL on screen come from ConfigMap {{ .Values.clusterConfig.configMapName }} in this namespace.

Open it:
{{- if .Values.ingress.enabled }}
  https://{{ include "snapwall.ingressHost" . | default "<the DNS name pointing at this cluster's ingress>" }}
{{- else }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "snapwall.fullname" . }} 8080:{{ .Values.service.port }}
  open http://localhost:8080
{{- end }}

Look at the disk:
  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "snapwall.fullname" . }} -- ls -lh /data/photos
  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "snapwall.fullname" . }} -- tail -f /data/heartbeat.log

Prove persistence:
  kubectl -n {{ .Release.Namespace }} delete pod -l app.kubernetes.io/instance={{ .Release.Name }}
